# Provenance

The frontend and test core are original code. No third-party emulator or frontend implementation
is used as an implementation reference. Cores are loaded as black boxes; their build recipes,
licences and public API documentation may be read.

| Source | Used for |
|---|---|
| `third_party/libretro/SOURCE` | Pinned official `libretro.h`, MIT; generated FFI, callbacks, environment commands, options, SRAM and serialization contracts. Header retained unmodified with its licence. |
| https://docs.libretro.com/library/snes9x/ | Published Snes9x extensions, core option names/defaults and required firmware. |
| https://docs.libretro.com/library/nestopia/ | NES formats, joypad inputs, firmware boundaries and published core options. Nestopia is queried and run as a black box. |
| https://www.nesdev.org/wiki/INES | Header layout for the original NROM smoke cartridge (no emulator code). |
| https://www.nesdev.org/wiki/PPU_registers | PPU address/data ports, palette/nametable writes and vblank polling for the original smoke cartridge. |
| https://www.nesdev.org/wiki/APU_Pulse | Pulse-channel registers for the smoke cartridge's quiet test tone. |
| https://www.nesdev.org/wiki/Controller_port_registers | Serial controller strobe/read protocol used by the original smoke cartridge. No example implementation was copied. |
| [nibkit](https://github.com/abradburne/nibkit) (MIT, fonts OFL-1.1) | Public nibOS SDK: screen placement, printed buttons, device controls, menu model/layout/raster, settings and DSlot descriptions. |

Bindings are generated by bindgen 0.72.1 (`tools/bindings`), without frontend source. Our C log
adapter uses only the standard C printf API and the libretro header's log callback signature.
Core packages and validation ROMs are recorded separately in `docs/validation.md`.

## Mega Drive, Game Gear and Lynx

- https://docs.libretro.com/library/blastem/ — public core documentation (currently sparse);
  actual options and six-button defaults were queried from the installed core API.
- https://docs.libretro.com/library/gearsystem/ — Game Gear formats, optional boot ROM,
  pixel geometry, input and memory/state contracts.
- https://docs.libretro.com/library/handy/ — Lynx cartridge format, required 512-byte BIOS,
  rotation and video update options. Runtime API confirms refresh values `50`/`60`/`75` etc.
- https://docs.libretro.com/library/gearlynx/ and
  https://docs.libretro.com/library/beetle_lynx/ — candidate comparison, firmware requirements;
  neither implementation was read or included.
- https://docs.libretro.com/library/genesis_plus_gx/ — candidate capabilities/licence boundary;
  extracted for evaluation, not selected for the nibOS integration or included in the frontend.
- https://github.com/drhelius/Gearsystem/tree/66fe79082349e1365af3ac9fd26ea526b3cc7233 —
  only `platforms/libretro/Makefile`, `Makefile.common` and `LICENSE` were read: native ARM build
  flags and licence. Emulator implementation was compiled and run as a black box.
- https://github.com/libretro/libretro-handy/tree/bc55d462f0b2d6b073ea93dc552ebd73cec60fd1 —
  only `Makefile`, `Makefile.common` and `lynx/license.txt` were read, for the same purpose.
- https://www.smspower.org/Development/GGOfficialDocs — Sega's hardware documentation:
  VDP/control/data ports, registers, palette, header region and memory map for our original
  Game Gear test program. No emulator or frontend code was used.
- https://www.smspower.org/Development/ControlPort and
  https://www.smspower.org/Development/VDPRegisters — documented port/register semantics.
- https://nemesis.hacking-cult.org/MegaDrive/Documentation/GenesisSoftwareManual.pdf —
  published Sega manual search excerpts for the VDP ports and CRAM addressing; full PDF fetch
  was unavailable. The spritesmind mirror was also attempted, but too large for the web tool.
- https://www.nxp.com/docs/en/reference-manual/M68000PRM.pdf — Motorola instruction encodings,
  branch/DBRA displacement semantics for our original Mega Drive smoke cartridge.

`tools/sega-smoke.py` emits original test programs, not shipped ROMs. The host's rotation
implementation follows the vendored MIT libretro header's counter-clockwise quarter turns.

## Game & Watch

- https://github.com/libretro/gw-libretro/tree/91d599b951e7bfe7e040347f58667cba20074adc —
  only `README.md`, `LICENSE` (zlib) and `Makefile.libretro` were read: what the core plays,
  its licence and its build. The core was compiled and run as a black box.
- How it lays out units, which inputs it reads (the pointer on port 2, which it reads but these
  conversions don't act on) and its Select / Start hand were measured from its frames and its
  `input_state` calls (`nibcase-test --frame`, `--press`, `--tap`, `NIBCASE_DEBUG=input`), on
  owned `.mgw` files, which are not in this repository.
- The hinge positions in `crates/nibcase/src/unit.rs` were measured from those frames.

## RetroAchievements

- nibkit's `nib-cheevos` (MIT), with rcheevos 12.4 (MIT, vendored there), RetroAchievements' own
  library: the session, rhash and `rc_libretro.c` (each console's memory over a libretro core's,
  and its rules for cores' options and consoles) were read, as was `libretro.h`'s memory map.
  No other emulator's or frontend's achievements code was read.
- The `chd` crate (chd-rs, BSD-3-Clause) decompresses CHD images for nib-cheevos' CD reader;
  its API and its CD frame layout were read.
- Sonic the Hedgehog's RAM map (Sonic Retro's wiki: the game mode at $FFF600) and the game's set
  as the service serves it (its memory references), for BlastEm's byte order.

## Master System, PC Engine, Neo Geo Pocket, WonderSwan, Disk System

- Cores, run as black boxes; only their build files and licences read: Gearsystem (already
  pinned, GPL-3.0), Beetle PCE Fast (Arch Linux ARM's `libretro-beetle-pce-fast`, GPL-2.0), Beetle
  NeoPop (`beetle-ngp-libretro` a50d5ac, GPL-2.0), Beetle Cygne (`beetle-wswan-libretro` 4b01295,
  GPL-2.0), Nestopia (Arch Linux ARM, GPL-2.0).
- WSdev wiki, "ROM header": a WonderSwan game's footer, the orientation flag in bit 0 of the
  byte 4 from the end (`systems::rom_defaults`).
- Test games, downloaded for testing only, never into this repository: Stalactites
  (haroldo-ok, MIT, v0.6), SwanSong Originals (RegionallyFamous, MIT, v3.3.0: Rotate Dungeon,
  Orbital Courier, One Last Lap), Asteroids Neo (underscore42), and PC Engine samples built from
  HuC's own examples (pce-devel/huc 54f5c73: shmup, scroll, promotion).
