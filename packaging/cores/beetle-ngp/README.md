# Neo Geo Pocket through Beetle NeoPop

The core is a separate package, `libretro-beetle-ngp`, built from this directory's PKGBUILD at a
pinned commit (GPL-2.0). Installing it with `nibcase-beetle-ngp` registers its options with DSlot
for Neo Geo Pocket and Pocket Color games: `.ngp`, `.ngc` or a `.zip` holding one, in `Roms/NGP`.
No BIOS is needed. No ROMs or firmware are distributed.
